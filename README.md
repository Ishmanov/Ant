# 🐜 AntSimulator

Визуальный симулятор «муравья Лэнгтона» на WPF (C#) с **настраиваемыми правилами**. Правила поведения муравья собираются из блоков перетаскиванием, а само движение сопровождается плавными анимациями.

## Возможности

- Поле произвольного размера (до 99×99) с настраиваемым шансом появления чёрных клеток
- Конструктор правил в стиле drag & drop: отдельные списки действий для белой и чёрной клетки
- Четыре действия: **Перекрасить**, **Направо**, **Налево**, **Идти прямо**
- Плавные анимации:
  - муравей скользит между клетками;
  - поворот выполняется анимацией угла;
  - клетки плавно меняют цвет
- Регулируемая задержка шага (10–300 мс)
- Тороидальное поле: при выходе за край муравей появляется с противоположной стороны
- Запуск, пауза и повторная генерация поля в любой момент

## Как это работает

На каждом шаге муравей смотрит на цвет клетки, на которой стоит, и берёт список действий для этого цвета. Затем он выполняет **одно действие за тик таймера**. Когда список закончился, цвет клетки проверяется заново и выполняется следующий список.

Классический муравей Лэнгтона задаётся так:

| Клетка | Правила (по порядку)                        |
|--------|---------------------------------------------|
| Белая  | Направо → Перекрасить → Идти прямо          |
| Чёрная | Налево → Перекрасить → Идти прямо           |

Можно экспериментировать с любыми другими комбинациями и смотреть, какие узоры получаются.

## Управление

| Элемент                    | Действие                                             |
|----------------------------|------------------------------------------------------|
| **Сгенерировать**          | Создаёт новое поле и ставит муравья в случайную клетку |
| **Запустить / Пауза**      | Запускает или приостанавливает симуляцию             |
| **Размер поля**            | Число строк × столбцов (до 2 цифр каждое)            |
| **Шанс покраски клетки**   | Вероятность, что клетка при генерации будет чёрной (%) |
| **Задержка шага**          | Интервал между шагами муравья                        |
| Перетаскивание блока       | Из палитры в нужный список правил                    |
| ПКМ по блоку в списке      | Удалить блок (нумерация пересчитывается)             |

## Запуск

Скачайте архив релиза, распакуйте его, запустите setup.exe

## Технические детали анимации

- **Муравей** — один `Polygon` на слое `Canvas` поверх `UniformGrid`. Позиция и поворот анимируются через `TranslateTransform` и `RotateTransform` (`DoubleAnimation`).
- **Угол поворота накапливается** (`+90` / `-90`), а не берётся по модулю 360. Поэтому стрелка не прокручивается назад при переходе через 0°.
- **Цвет клеток** анимируется через `ColorAnimation`. У каждой клетки своя незамороженная `SolidColorBrush`, потому что общие `Brushes.Black` и `Brushes.White` анимировать нельзя.
- **Состояние поля** хранится в массиве `bool[]`, а не вычисляется по цвету кистей.
- **Длительность анимации** равна 90% от интервала таймера, поэтому она успевает завершиться до следующего шага.
- Движение линейное (без easing), чтобы муравей не «спотыкался» на каждой клетке. Для поворота и смены цвета используются easing-функции.
